# Phase 0 Discovery Handoff

## Objective

Audit the existing FukasawaGPT and Agent Foundry doctrine and convert it into a runtime contract inventory.

## Inputs

- `../FukasawaGPT/# FukasawaGPT.md`
- `../FukasawaGPT/Fukasawa_Task_Depth_Framework.md`
- `../FukasawaGPT/Workflow_Design_Brief.md`
- `../FukasawaGPT/# Non-Conformance Improvement Opportunit.md`
- `../agent_foundry_gpt_builder_brief_v_1 (1).md`
- `docs/architecture.md`

## Tasks

1. Extract all named concepts into a glossary.
2. Identify every implied runtime object.
3. Map each runtime object to source doctrine.
4. Identify contradictions, duplicates, and missing contracts.
5. Choose one pilot workflow.
6. Write a Phase 0 findings report.

## Output

- `docs/glossary.md`
- `docs/source-to-contract-map.md`
- `planning/phase-0-findings.md`
- selected pilot workflow decision

## Review Gate

Human review is required before Phase 1 begins because schema names and object boundaries become durable API language.
